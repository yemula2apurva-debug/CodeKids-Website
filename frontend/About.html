About CodeKids

Our Mission


Our website is designed to introduce students to the basics of web development in a simple, easy and interesting way.
Web development mainly uses three important technologies: HTML, CSS and JavaScript. HTML, or HyperText Markup Language, is used to create the basic structure and content of a website, such as headings, paragraphs, images, links, buttons and forms.
CSS, or Cascading Style Sheets, is used to make the website attractive by adding colors, fonts, layouts, spacing, backgrounds, animations and responsive designs.


JavaScript is a programming language that makes websites interactive and dynamic by allowing features such as quizzes, games, buttons, animations, calculators and other user interactions. HTML provides the structure, CSS provides the design, and JavaScript provides the functionality. Together, these three technologies help us create modern, attractive and interactive websites.
Our goal is to help beginners and school students understand these technologies easily, develop their coding skills and gain confidence to create their own creative web projects.





🎯 Our Objectives


  • 👨‍💻 Introduce children to the basics of coding


  • 🧠 Develop logical thinking and problem-solving skills


  • 🎨 Encourage creativity through technology


  • 🤖 Introduce children to robotics and interactive activities


  • 💡 Help students understand how technology works in everyday life


  • 🚀 Build curiosity and confidence to learn more about technology
